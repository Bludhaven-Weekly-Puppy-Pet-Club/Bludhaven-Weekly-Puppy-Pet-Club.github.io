      공통 비밀번호 변경

      잠금 카테고리의 공통 비밀번호는 이 화면에서 바꾸지 않습니다. 아래 순서로 바꿉니다.

      1. GitHub 저장소 Bludhaven-Weekly-Puppy-Pet-Club/blog-source의 Settings → Secrets and variables → Actions로 갑니다.
      2. Repository secrets의 PRIVATE_PASSWORD를 새 비밀번호로 수정합니다.
      3. Actions 탭에서 배포 워크플로를 다시 실행합니다(Run workflow). 배포가 끝나면 새 비밀번호가 적용됩니다.

      비밀번호를 바꾸면 멤버들에게 새 비밀번호를 직접 알려 주세요. 이미 잠금을 푼 기기도 새 비밀번호를 다시 입력해야 합니다.
